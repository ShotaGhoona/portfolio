# PR作成コマンド

以下の手順でPRを作成する。

## 引数

`$ARGUMENTS` からベースブランチとPR概要を受け取る。
- ベースブランチ: 第1引数（指定がない場合は main）
- PR概要: 第2引数（指定がない場合はコミット内容から推測）

## 手順

### 1. 現在の状態を確認

- `git status` で未コミットの変更がないか確認
- 現在のブランチ名を確認

### 2. リモートの最新を取得

- `git fetch origin {ベースブランチ}` でリモートの最新状態を取得

### 3. コミット履歴を確認

- `git log origin/{ベースブランチ}..HEAD --oneline` で差分コミットを確認
- 各コミットの内容を把握

### 4. 差分を確認

- `git diff origin/{ベースブランチ}...HEAD --stat` で変更ファイルの概要を確認

### 5. PRテンプレートを参照

- `.github/pull_request_template.md` の形式に従う

### 6. PRを作成

- `gh pr create --base {ベースブランチ}` でPRを作成
- タイトルはコミット内容を要約したもの
- 本文はテンプレートに沿って記述

## PRテンプレート形式

```
## やったこと
<!-- コミット内容から要約 -->

## 影響範囲
<!-- 変更ファイルから推測 -->

## 備考
<!-- 必要に応じて -->

## チェックリスト
- [x] 自身のコードをセルフレビューしましたか？
- [x] コーディング規約/フォーマッターに従っていますか？
- [x] 不要な `console.log` やデバッグコードを削除しましたか？
```

## 注意事項

- PRのbodyはHEREDOCを使用して正しくフォーマットすること
- 未プッシュの場合は先にプッシュすること
